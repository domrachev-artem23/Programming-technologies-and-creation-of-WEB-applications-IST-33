# Практическая работа 11 — вариант 9

Отдельная backend-работа FinBuddy: REST API на Node.js/Express и PostgreSQL находится в папке `backend/`. React-интерфейс в эту сдачу не входит.

Реализованы пользователи с регистрацией и JWT-входом, категории пользователя, CRUD расходов, проверка владельца записей, поиск по описанию, фильтр по категории и периоду, сумма за период, группировка категорий с процентными долями и ежедневная динамика.

## Настройка и запуск

Нужны Node.js 20+ и PostgreSQL. Создайте пустую базу `finbuddy`, скопируйте `backend/.env.example` в `backend/.env` и укажите собственный пароль PostgreSQL и длинный случайный `JWT_SECRET`.

```powershell
cd backend
npm install
npm run db:init
npm start
```

Проверка доступности: `GET http://localhost:3000/api/health`. Маршруты расходов и статистики принимают JWT в `Authorization: Bearer <token>`. Подробное описание endpoint-ов и параметров периодов находится в `backend/README.md`.

## Быстрый запуск в Windows

Сначала убедись, что PostgreSQL запущен, затем дважды щёлкни start-lab11.bat. Скрипт подготовит базу, запустит API на порту 3001 (или следующем свободном) и автоматически запустит сайт lab10.

## Структура backend

- src/routes — маршруты API по разделам.
- src/controllers — обработчики регистрации, категорий, расходов и статистики.
- src/middleware/auth.js — проверка JWT и владельца данных.
- src/db/pool.js — подключение к PostgreSQL.
- src/utils — проверка входных данных и общая обработка async-ошибок.
- src/app.js — настройка Express и подключение маршрутов.
- src/server.js — запуск и корректное завершение сервера.
