# Практическая работа 13 — FinBuddy PWA, вариант 9

Мобильный трекер расходов: адаптивный интерфейс, manifest, Service Worker, офлайн-кэш оболочки, локальное хранение операций, поиск, фильтры, категории, диаграмма, CSV и резервная копия.

## Запуск
Дважды нажмите run-lab13.bat. Сайт откроется на http://127.0.0.1:8133. Для Service Worker страница запускается через HTTP, а не открывается из файла. После первого посещения оболочка доступна офлайн. Данные хранятся в браузере на этом устройстве.

Для установки PWA на смартфон через интернет потребуется публикация по HTTPS.
