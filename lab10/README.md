# Практическая работа 10 — вариант 9

React-интерфейс FinBuddy: навигация, поиск, категории, добавление/изменение/удаление операций, диаграмма расходов и отчёты. В демо-режиме есть примеры за август–октябрь 2024 года и январь–ноябрь 2026 года. В демо-режиме изменения хранятся в состоянии страницы.

## Запуск сайта

1. Установите Node.js 20+ и PostgreSQL.
2. Для настоящего аккаунта сначала запустите соседнюю папку lab11 двойным щелчком по start-lab11.bat и дождитесь проверки API.
3. Запустите start-lab10.bat. При первом запуске он установит frontend-пакеты и откроет сайт на localhost:5173.
4. В нижней части бокового меню нажмите «Демо-режим · Войти», выберите регистрацию и заполните имя, почту и пароль. Аккаунт и операции будут сохранены в PostgreSQL через API работы 11.

Без запущенной lab11 сайт работает в демо-режиме; вход и регистрация требуют backend и PostgreSQL. Не открывайте frontend/index.html через Live Server — используйте start-lab10.bat.
