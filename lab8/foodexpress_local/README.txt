FOODEXPRESS — ЛОКАЛЬНЫЕ ФОТОГРАФИИ

1. Распакуйте архив целиком в отдельную папку.
2. Для первоначальной загрузки фотографий нужен Python 3 и интернет.
3. Дважды щёлкните файл «Скачать_фото.bat».
4. Дождитесь окончания загрузки. Фотографии сохранятся в папку img.
5. Откройте index.html в браузере.

BAT-файл запускает download_images.py через Python. PowerShell и изменение
ExecutionPolicy не используются.

Если появится сообщение «Python не найден», установите Python 3:
https://www.python.org/downloads/windows/
При установке отметьте «Add Python to PATH», затем запустите BAT-файл снова.

После успешной загрузки сами фотографии будут храниться локально в папке img.
Интернет для их отображения больше не нужен. Внешние Bootstrap и Google Fonts
в исходном дизайне всё ещё подключаются через CDN.
